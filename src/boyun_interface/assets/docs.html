1. Set up a world

Choose an offline example or configure a supported author. Review actors, budgets, information links and action effects before approving execution.

2. Choose model access

Offline rules make no model requests. Hosted providers receive the selected inputs. Imported keys live in the server process until forgotten or stopped.

3. Run and inspect

Approve the reviewed call ceiling. The engine settles feasible actions, records state and exposes reports. Saved decisions support replay without new inference. Model scores are not calibrated market probabilities.

4. Export and verify

Download results or Markdown/PDF reports. Optional NEAR testnet submission requires a separate approval and verifies artifact integrity, not forecasting accuracy.
